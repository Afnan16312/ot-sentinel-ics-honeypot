# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue containing exploit details, raw attacker telemetry, credentials or personal information. Contact the repository owner privately through the security advisory feature on GitHub.

## Deployment warning

This project intentionally exposes simulated industrial protocol services. Deploy it only in an isolated cloud resource group or research network that you own and are authorized to operate. Never deploy it alongside production, corporate, home or operational-technology assets.
